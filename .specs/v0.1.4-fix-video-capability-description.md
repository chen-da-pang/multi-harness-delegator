**Status**: ✅ Implemented

---

## 问题

当前 `SKILL.md` 关于视频分析能力的描述有多处错误：

1. **错误 1**: 说"Grok 支持视频分析"
   - **实际**: Grok **不支持视频**
   
2. **错误 2**: 说"GLM 5.3 Flash 智商蠢"
   - **实际**: Flash 只在**非多模态任务**时蠢（代码、推理等），多模态分析本身不蠢

3. **错误 3**: 说"推荐 Grok/Antigravity 做视频分析"
   - **实际**: 这两个**都不支持视频**

4. **错误 4**: 未明确"GLM 5.3 Flash 是唯一能看视频的模型"

---

## 需求

修正所有关于视频分析能力的错误描述：

### 1. 能力矩阵修正

| 模型 | 图片 | 视频 | 音频 | 备注 |
|------|------|------|------|------|
| GLM 5.3 Flash | ✓ | ✓ | ✗ | **唯一能看视频**，但听不到音频 |
| Grok 4.7 Fast | ✓ | ✗ | ✓ | 不支持视频 |
| Antigravity | ✓ | ✗ | ✓ | 不支持视频 |
| Gemini 3.8 Flash | ✓ | ✗ | ✗ | 不支持视频 |

### 2. 决策树修正

```
任务需要多模态？
└─ Yes & 需要看**视频** → ZCode GLM-5.3-Flash（唯一选项）
└─ Yes & 需要听**声音** → Grok Build / Antigravity（但不支持视频）
└─ Yes & 只需要看**图片** → Grok 4.7 Fast / Gemini 3.8 Flash
└─ No → 继续
```

### 3. 禁止做法更新

添加：
- ❌ 把需要看视频的任务交给 Grok/Antigravity（它们不支持视频）
- ❌ 把代码/推理任务交给 ZCode GLM-5.3-Flash（它在非多模态任务时蠢）

### 4. 测试结果表格更新

| 任务类型 | 推荐 |
|----------|------|
| 视频分析（有声音） | ZCode GLM-5.3-Flash（妥协方案：能看但听不到） |
| 视频分析（无声音/可接受无声） | ZCode GLM-5.3-Flash（唯一选项） |
